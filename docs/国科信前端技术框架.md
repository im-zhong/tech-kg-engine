## 四、项目结构

```Plaintext
src/
├── api/                        # API 接口层
│   ├── module/                 # 按业务模块拆分的 API 文件

│   └── factoryFn.js            # 工厂函数

│   ├── common/                 # 公共资源

│   └── svg/                    # SVG 图标
├── components/                 # 通用组件
│   ├── CodeEditor/             # 代码编辑器封装
├── constants/                  # 常量定义
│   ├── encrypt-config.ts       # 加密配置
├── directive/                  # 自定义指令
├── hooks/                      # 组合式函数（Composables）
│   ├── eventSource.js          # SSE 事件源
│   ├── inputArouseKeyHook.ts   # 输入键事件
│   ├── notificationHook.ts     # 通知钩子
│   └── redMessage.ts           # 小红点消息
├── layouts/                    # 布局组件
│   ├── WorkspaceLayout.vue     # 工作空间布局
│   ├── PreviewLayout.vue       # 预览布局
│   └── ShareLayout.vue         # 分享布局
├── locales/                    # 国际化资源
│   ├── zh-CN.js
│   └── en-US.js
├── router/                     # 路由配置
├── stores/                     # Pinia 状态管理
│   ├── userSettings.js         # 用户设置
│   ├── userWorkflows.js        # 用户工作流
│   └── ...
├── utils/                      # 工具函数
│   ├── auth.ts                 # 认证
│   ├── common.js               # 通用工具
│   └── ...
├── views/                      # 页面视图
│   ├── AiSpace/                # AI 空间
│   ├── KnowledgeBase/          # 知识库
│   ├── ModelManage/            # 模型管理
│   ├── Workspace/              # 工作空间（工作流编辑器）
│   ├── Plugins/                # 插件市场
│   ├── AppMarket/              # 应用市场
│   ├── Login/                  # 登录
│   ├── DataBase/               # 数据库
│   ├── QingliuChat/            # 清流对话
│   └── ...
├── App.vue
└── main.js
```
